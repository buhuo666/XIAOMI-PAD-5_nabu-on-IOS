# GPU244 来源统计与 GPU245 命令流记录优化

2026-11-13。GPU244 15秒滑动采集 242,173 条 trace，零丢失；893次DPU接受、0拒绝，最忙整秒82次，823个完整关联输出。全程实际120fps仍未达到。

原始资源记录45,237,374条，唯一记录893,849条。来源精确加总一致：CS命令流44,794,798条（99.02%），命令缓冲自身425,108条，普通描述符集3,150条，IB 14,318条。普通set引用1,050次，命令缓冲14,284个。数量占比不等于耗时占比。

GPU CP→RB平均12.164ms，561/823超过8.333ms；资源收集平均0.955ms，其中最终去重0.702ms。GPU244槽1尚未回收，替换启动包前须先回收。原始证据：`log/host/gpu-v244/desktop-01/`。

GPU245只将CS资源记录的最近16条回看改为精确IOVA/size索引，重复范围合并access位。CS转发沿用原函数，通过索引停止再次追加重复范围；reset清索引，finish释放。命令缓冲自身的记录函数和GPU指令不变。

主机检查执行实际记录、转发、最终collector、BO查找与清理函数；35组语义、51个分配失败点、40项冲突链及ASan/UBSan通过。比较每个BO区间的有效访问权限和保留引用，不要求中间数组形状一致。完整构建还需确认实际源码生命周期接线。

合成584个唯一范围、32次重复及3次转发，中位数2.081→0.107ms；128次重复8.827→0.347ms。仅为主机合成基准，不能当作iPadOS收益。后续实机比较CS原始记录、编码和提交耗时；GPU执行工作量仍需单独优化。
