# 特殊步骤清单

更新：2026-11-06，Asia/Shanghai。以下为用户明确指定的项目工作规则，后续接续任务时继续执行。

当前任务：用户于2026-11-06明确开始修复Wi-Fi和蓝牙，按更新的[基本技术路线](BASIC-TECHNICAL-ROADMAP.md)推进无线驱动。已有系统和应用成果保留，软件剩余项继续记录。当前不使用Apple服务器激活及Apple ID、App Store、iCloud等官方服务器服务。仍限定原有64GiB区域并沿用APFS。

1. **访问和下载走本地代理。** 网络访问、源码拉取、API 请求、文件下载统一使用本地代理；当前地址为 `http://127.0.0.1:19999`。
2. **本地无法反编译的走 GitHub Actions。** 本地工具不支持目标或无法完成反编译时，将任务交给 GitHub Actions，并取回分析结果。
3. **文件只在下载时进行审查。** 下载时完成一次审查；后续使用已有文件时，不重复进行文件审查或哈希审计。
4. **不进行防御性编程。** 按实际需求和已出现的错误直接实现、修复，不增加假设性校验、冗余兜底或重复检查。
5. **实机反馈提供选项。** 请求用户反馈启动、操作或回到Android的状态时，使用带选项的问题，避免要求自由输入固定回复。

新增特殊步骤继续补充到本清单。
